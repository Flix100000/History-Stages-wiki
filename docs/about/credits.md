# Credits

History Stages is built by **Flix100000** and **PixlStudios**.

Translations beyond German and English come from the community. The German and English language
files are maintained in the repository; every other language is contributed, and corrections to
them are welcome as pull requests.

Thanks to everyone who has reported a bug with a log attached, argued a design decision in Discord,
or built a pack big enough to find the edges.

## The mod

[CurseForge](https://www.curseforge.com/minecraft/mc-mods/history-stages) ·
[Modrinth](https://modrinth.com/mod/history-stages) ·
[GitHub](https://github.com/Flix100000/History-Stages) ·
[Discord](https://discord.gg/BeZzxyZ9c4)

The source is public. It is **not** open source — see `LICENSE.txt` in the repository for the terms
that actually apply, and [Porting & Permissions](/wiki/about/porting) for what a port needs.

## Contributing

Bug reports, feature requests and pull requests all go through
[GitHub](https://github.com/Flix100000/History-Stages). The repository's `CONTRIBUTING.md` has the
build instructions and the house rules.

Documentation lives in its own repository —
[History-Stages-wiki](https://github.com/Flix100000/History-Stages-wiki). Every page has an
"Edit this page" link at the bottom.
